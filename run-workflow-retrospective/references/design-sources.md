# Design sources

This skill adapts principles from:

- glebis/claude-skills retrospective: transcript mining, user corrections, repeated failures, and concrete actions.
  https://github.com/glebis/claude-skills/blob/46edb03cc915adbd78ee81e3406bc4480aefcaba/retrospective/SKILL.md
- Rune engineering retrospective: quantitative churn, test health, and trend comparison.
  https://github.com/Rune-kit/rune/blob/19fac25e58355adf92d858bbc8524b786eaabf0d/skills/retro/SKILL.md
- Retro Harness: validate workflow improvements against prior trajectories with bounded tests rather than a large optimizer.
  https://github.com/wbopan/retro-harness
- Matt Pocock diagnosing-bugs: deterministic red-capable feedback, minimal repros, and falsifiable hypotheses.
  https://github.com/mattpocock/skills/blob/main/skills/engineering/diagnosing-bugs/SKILL.md
- Matt Pocock to-tickets: independently verifiable tracer bullets that fit one fresh context.
  https://github.com/mattpocock/skills/blob/main/skills/engineering/to-tickets/SKILL.md
- Matt Pocock code-review: separate spec fidelity from engineering standards.
  https://github.com/mattpocock/skills/blob/main/skills/engineering/code-review/SKILL.md
- Matt Pocock improve-codebase-architecture: use churn to find architectural friction and smaller interfaces.
  https://github.com/mattpocock/skills/blob/main/skills/engineering/improve-codebase-architecture/SKILL.md
