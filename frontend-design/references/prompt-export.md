# Prompt export

Read this when the requested output is a prompt for an external UI generator or a bounded one-off design worker, and the direction is already settled. Export instead of designing again.

Read `BRIEF.md`, `DESIGN.md`, `DECISIONS.md` and the relevant references or brand assets. Assemble the prompt from the Design Inputs frame in `SKILL.md` (Task, Context, Examples, Behavior, Constraints) plus:

- **Visual Thesis**: macrostructure, tone, type roles, density, motion stance, color anchors, from `DESIGN.md`.
- **Output Contract**: files, fidelity, states, prompt-only or code, what not to invent.

Produce the prompt only, unless the user asks to run it. Keep the approved macrostructure, thesis, tokens and anti-pattern notes intact, state which artifacts the prompt was built from, and mark unknowns rather than inventing proof, metrics or brand assets. If the prompt would require choosing a new direction, stop and run the variant workflow.
