# Reference study

Read this when the user provides a screenshot, website or visual reference. Study it for design DNA rather than cloning pixels.

Extract: structure and macrostructure; type roles and hierarchy; density and whitespace rhythm; color anchors and restraint; interaction stance (playful, quiet, tactile, editorial, operational).

Then state what to preserve, what to translate into the local product context, and what to avoid copying literally. Good adaptation preserves stance and structure while changing content, constraints and implementation details to fit the project.

Reference safety:

- Do not copy proprietary layouts, copy, images or templates wholesale.
- Turn a reference into a reusable `DESIGN.md` only for the user's own project or brand, or a public reference they are allowed to adapt.
- For auth-walled, JS-only or unreadable URLs, ask for a screenshot or a brief description instead of guessing.
